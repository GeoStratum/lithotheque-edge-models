1. RÉCUPÉRATION DES INFOS SYSTÈME, WINDOWS & PILOTES
--------------------------------------------------------------------------------
Ouvrir PowerShell (pwsh ou powershell) sur le PC Snapdragon et lancer :

A. Informations Windows & Build exacte :
   Get-ComputerInfo | Select-Object WindowsProductName, WindowsVersion, OsBuildNumber, OsHardwareAbstractionLayer

B. Modèle exact du processeur & NPU :
   Get-CimInstance Win32_Processor | Select-Object Name, NumberOfCores, NumberOfLogicalProcessors, MaxClockSpeed

C. GPU & Version exacte du pilote Adreno :
   Get-CimInstance Win32_VideoController | Select-Object Name, DriverVersion, DriverDate

D. Version des pilotes Qualcomm NPU / Hexagon :
   Get-PnpDevice -Class "ComputeAccelerator" | Select-Object FriendlyName, InstanceId, Status
   # Ou alternativement :
   Get-PnpDevice | Where-Object { $_.FriendlyName -like "*Qualcomm*" -or $_.FriendlyName -like "*Hexagon*" -or $_.FriendlyName -like "*NPU*" } | Select-Object FriendlyName, Status

E. Mémoire RAM réelle et vitesse :
   Get-CimInstance Win32_PhysicalMemory | Select-Object Capacity, Speed, MemoryType

3. TESTS DE LATENCE SUR LE NPU HEXAGON / CPU / GPU
--------------------------------------------------------------------------------

Option A : Via le benchmark LiteRT / TFLite (benchmark_model.exe ARM64 natif)
   1. Télécharger ou utiliser le binaire benchmark_model de LiteRT ARM64.
   2. Tester le NPU Hexagon (via delegate QNN / HTP) :
      .\benchmark_model.exe --graph=best_mobilenetv5_rocks_w4a8.tflite --num_runs=100 --warmup_runs=10 --use_nnapi=false --use_qnn=true --qnn_backend=htp
   3. Tester le CPU (Oryon avec XNNPACK) :
      .\benchmark_model.exe --graph=best_mobilenetv5_rocks_w4a8.tflite --num_runs=100 --warmup_runs=10 --use_xnnpack=true --num_threads=4
   4. Tester le GPU (Adreno via OpenCL/Vulkan) :
      .\benchmark_model.exe --graph=best_mobilenetv5_rocks_w4a8.tflite --num_runs=100 --warmup_runs=10 --use_gpu=true

Option B : Via onnxruntime-qnn (Python sous ARM64)
   Dans un environnement Python ARM64 avec onnxruntime-qnn :
   1. Vérifier la détection du provider QNN :
      python -c "import onnxruntime as ort; print(ort.get_available_providers())"
      # Doit afficher ['QNNExecutionProvider', 'CPUExecutionProvider']
   2. Lancer la session avec le provider QNN :
      ```python
      import onnxruntime as ort
      import numpy as np
      import time

      options = ort.SessionOptions()
      provider_options = [{
          'backend_path': 'QnnHtp.dll', # Accélérateur NPU Hexagon
          'htp_performance_mode': 'burst'
      }]
      session = ort.InferenceSession('best_mobilenetv5_rocks_w4a8.onnx', options, providers=['QNNExecutionProvider'], provider_options=provider_options)

      dummy_input = np.zeros((1, 256, 256, 3), dtype=np.int8)
      # Warmup
      for _ in range(10): session.run(None, {'pixel_values': dummy_input})
      
      # Mesure sur 100 runs
      latencies = []
      for _ in range(100):
          t0 = time.perf_counter()
          session.run(None, {'pixel_values': dummy_input})
          latencies.append((time.perf_counter() - t0) * 1000)
      print(f"Latence moyenne NPU Hexagon W4A8 : {np.mean(latencies):.2f} ms")
      ```
