ÉTAPE 1 : AUDIT SYSTÈME, PILOTES & MATÉRIEL (POWERSHELL)
================================================================================
Ouvrir PowerShell (pwsh) en mode normal ou administrateur et copier-coller :

1.1. Informations Windows & Build exacte :
--------------------------------------------------
Get-ComputerInfo | Select-Object WindowsProductName, WindowsVersion, OsBuildNumber, OsHardwareAbstractionLayer

1.2. Modèle exact du processeur & NPU :
--------------------------------------------------
Get-CimInstance Win32_Processor | Select-Object Name, NumberOfCores, NumberOfLogicalProcessors, MaxClockSpeed

1.3. GPU & Version exacte du pilote Adreno :
--------------------------------------------------
Get-CimInstance Win32_VideoController | Select-Object Name, DriverVersion, DriverDate

1.4. Pilotes Qualcomm Hexagon NPU & Accélérateurs :
--------------------------------------------------
Get-PnpDevice -Class "ComputeAccelerator" | Select-Object FriendlyName, InstanceId, Status
# Si vide, rechercher globalement :
Get-PnpDevice | Where-Object { $_.FriendlyName -like "*Qualcomm*" -or $_.FriendlyName -like "*Hexagon*" -or $_.FriendlyName -like "*NPU*" } | Select-Object FriendlyName, Status

1.5. RAM totale, type et fréquence réelle :
--------------------------------------------------
Get-CimInstance Win32_PhysicalMemory | Select-Object Capacity, Speed, ConfiguredClockSpeed, MemoryType

Astuce : Tu peux tout exporter en un fichier texte sur le bureau avec :
"=== AUDIT SNAPDRAGON ===" > "$HOME\Desktop\specs_snapdragon.txt"
Get-ComputerInfo | Select-Object WindowsProductName, WindowsVersion, OsBuildNumber >> "$HOME\Desktop\specs_snapdragon.txt"
Get-CimInstance Win32_Processor | Select-Object Name, NumberOfCores, MaxClockSpeed >> "$HOME\Desktop\specs_snapdragon.txt"
Get-CimInstance Win32_VideoController | Select-Object Name, DriverVersion >> "$HOME\Desktop\specs_snapdragon.txt"
Get-CimInstance Win32_PhysicalMemory | Select-Object Capacity, Speed >> "$HOME\Desktop\specs_snapdragon.txt"

ÉTAPE 2 : PRÉPARATION DE L'ENVIRONNEMENT PYTHON ARM64
================================================================================
Sur Windows 11 ARM64, privilégier Python ARM64 natif (Python 3.11 ou 3.12 ARM64 depuis python.org ou le Microsoft Store).

Dans votre terminal :
1. Installer les dépendances d'inférence :
   pip install numpy onnx

2. Installer ONNX Runtime avec support Qualcomm QNN :
   pip install onnxruntime-qnn
   # Ou si vous utilisez le paquet officiel Qualcomm QAIRT SDK :
   # Le SDK QAIRT fournit les DLLs HTP : QnnHtp.dll, QnnHtpPrepare.dll, libQnnHtpV73.so, etc.

3. Vérifier la présence du backend QNN :
   python -c "import onnxruntime as ort; print('Providers dispos:', ort.get_available_providers())"
   # Le résultat doit lister 'QNNExecutionProvider' et 'CPUExecutionProvider'.

ÉTAPE 4 : SCRIPT PYTHON DE BENCHMARK AUTOMATISÉ (1 CLIC)
================================================================================
Créer un fichier `benchmark_snapdragon.py` à côté des modèles et exécuter :
`python benchmark_snapdragon.py`

Code du script complet :
--------------------------------------------------------------------------------
import time
import numpy as np
import onnxruntime as ort

MODELS = {
    "W4A8 Full Int": "onnx/best_mobilenetv5_rocks_w4a8.onnx",
    "INT8 (W8A8)": "onnx/best_mobilenetv5_rocks_int8.onnx"
}

def benchmark_backend(model_path, provider_name, provider_options=None, num_runs=100, warmup=10):
    options = ort.SessionOptions()
    options.graph_optimization_level = ort.GraphOptimizationLevel.ORT_ENABLE_ALL
    
    providers = [provider_name]
    p_opts = [provider_options] if provider_options else None
    
    try:
        session = ort.InferenceSession(model_path, options, providers=providers, provider_options=p_opts)
    except Exception as e:
        return f"Erreur chargement: {e}"
        
    input_name = session.get_inputs()[0].name
    # Tensor INT8 [-128, 127] shape (1, 256, 256, 3)
    dummy_input = np.random.randint(-128, 127, size=(1, 256, 256, 3), dtype=np.int8)
    
    # Warmup
    for _ in range(warmup):
        session.run(None, {input_name: dummy_input})
        
    # Benchmark
    latencies = []
    for _ in range(num_runs):
        t0 = time.perf_counter()
        session.run(None, {input_name: dummy_input})
        latencies.append((time.perf_counter() - t0) * 1000.0)
        
    avg = np.mean(latencies)
    std = np.std(latencies)
    p95 = np.percentile(latencies, 95)
    return f"{avg:.2f} ms (p95: {p95:.2f} ms)"

print("="*60)
print("DÉBUT DU BENCHMARK LITHOTHEQUE SUR SNAPDRAGON ARM64")
print("="*60)

for tag, path in MODELS.items():
    print(f"\n--- Évaluation du Modèle : {tag} ({path}) ---")
    
    # 1. NPU Qualcomm Hexagon (HTP Backend)
    npu_opts = {'backend_path': 'QnnHtp.dll', 'htp_performance_mode': 'burst'}
    res_npu = benchmark_backend(path, 'QNNExecutionProvider', npu_opts)
    print(f"  [NPU Hexagon] : {res_npu}")
    
    # 2. CPU Oryon ARM64
    res_cpu = benchmark_backend(path, 'CPUExecutionProvider')
    print(f"  [CPU Oryon]   : {res_cpu}")

print("\nBenchmark terminé !")
